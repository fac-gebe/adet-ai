Laravel backend

Create the public POST /api/generate endpoint. It accepts a question without login.

1. Gemini API key and server settings

Set these three values in the Laravel .env. Replace existing entries with the same names.

  1. Open Google AI Studio → API Keys and sign in with your Google account.
  2. Copy your existing key, or select Create API key and follow the prompts to choose or create a project.
  3. Paste the key after GEMINI_API_KEY= in the Laravel .env. Keep the key private on your Laravel server.
Laravel .env
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
CACHE_STORE=file

2. Gemini configuration

Add this entry inside the existing return [ ... ]; array in config/services.php.

config/services.php
'gemini' => [
    'key' => env('GEMINI_API_KEY'),
    'model' => env('GEMINI_MODEL', 'gemini-3.8-flash'),
],

3. AI controller

Create app/Http/Controllers/AiController.php and paste the entire block.

app/Http/Controllers/AiController.php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Client\ConnectionException;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Validator;

class AiController extends Controller
{
    public function generate(Request $request): JsonResponse
    {
        $validator = Validator::make($request->only('prompt'), [
            'prompt' => ['required', 'string', 'max:2000'],
        ]);

        if ($validator->fails()) {
            return response()->json(['message' => $validator->errors()->first()], 422);
        }

        $key = config('services.gemini.key');
        $model = config('services.gemini.model');

        if (! is_string($key) || trim($key) === '' || ! is_string($model) || trim($model) === '') {
            return response()->json(['message' => 'The AI service is not configured.'], 503);
        }

        try {
            $response = Http::withHeaders(['x-goog-api-key' => $key])
                ->acceptJson()
                ->connectTimeout(5)
                ->timeout(30)
                ->post("https://generativelanguage.googleapis.com/v1beta/models/{$model}:generateContent", [
                    'systemInstruction' => [
                        'parts' => [
                            ['text' => 'You are an IT311 study assistant. Explain IT concepts in plain language. Keep answers under 100 words.'],
                        ],
                    ],
                    'contents' => [
                        ['role' => 'user', 'parts' => [['text' => $validator->validated()['prompt']]]],
                    ],
                    'generationConfig' => ['maxOutputTokens' => 2048],
                ]);
        } catch (ConnectionException) {
            return response()->json(['message' => 'Could not reach the AI service. Try again.'], 503);
        }

        if ($response->status() === 429) {
            return response()->json(['message' => 'The AI service reached its rate limit. Try again later.'], 429);
        }

        if (! $response->successful()) {
            return response()->json(['message' => 'The AI service is unavailable. Try again later.'], 503);
        }

        $text = trim(collect($response->json('candidates.0.content.parts', []))
            ->reject(fn ($part) => data_get($part, 'thought', false))
            ->pluck('text')
            ->filter(fn ($part) => is_string($part))
            ->implode("\n"));

        if ($text === '') {
            return response()->json(['message' => 'The AI returned no text. Try another prompt.'], 502);
        }

        return response()->json(['text' => $text]);
    }
}

4. Public API route

If routes/api.php is new, paste the entire block. If it already exists, add any missing imports at the top and add the Route::post(...) block alongside your other routes.

routes/api.php
<?php

use App\Http\Controllers\AiController;
use Illuminate\Support\Facades\Route;

Route::post('/generate', [AiController::class, 'generate'])
    ->middleware('throttle:5,1');

5. API route registration

Open bootstrap/app.php. Add this line inside withRouting(...) if an api: entry is missing. If the entry is already there, mark this step complete.

bootstrap/app.php
api: __DIR__.'/../routes/api.php',

React Native app

Set the Laravel URL and paste the Study Helper screen.

6. Backend URL

Set this value in the React Native .env. The example is for an Android emulator on the computer running Laravel. On a physical phone, use a server URL the phone can reach. Leave /api out of the URL. Restart Expo after changing it.

React Native .env
EXPO_PUBLIC_API_URL=http://10.0.2.2:8000

7. Study Helper screen

Replace the entire home screen file. If your project uses app/ at its root, paste into app/index.tsx.

src/app/index.tsx
import axios from 'axios';
import { useState } from 'react';
import {
  ActivityIndicator,
  Button,
  ScrollView,
  StyleSheet,
  Text,
  TextInput,
} from 'react-native';

const API_URL = process.env.EXPO_PUBLIC_API_URL?.trim().replace(/\/+$/, '');

export default function StudyHelperScreen() {
  const [prompt, setPrompt] = useState('');
  const [answer, setAnswer] = useState('');
  const [error, setError] = useState('');
  const [loading, setLoading] = useState(false);

  async function generate() {
    const question = prompt.trim();
    if (loading || !question) return;

    setAnswer('');
    setError('');

    if (!API_URL) {
      setError('Set EXPO_PUBLIC_API_URL in the React Native .env file.');
      return;
    }

    setLoading(true);

    try {
      const { data } = await axios.post<{ text: string }>(
        `${API_URL}/api/generate`,
        { prompt: question },
        { headers: { Accept: 'application/json' }, timeout: 45000 },
      );

      if (typeof data?.text === 'string' && data.text.trim()) {
        setAnswer(data.text);
      } else {
        setError('The backend returned no answer.');
      }
    } catch (requestError) {
      const message = axios.isAxiosError<{ message?: string }>(requestError)
        ? requestError.response?.data?.message
        : undefined;

      setError(typeof message === 'string' ? message : 'Could not reach the backend. Check the server URL.');
    } finally {
      setLoading(false);
    }
  }

  return (
    <ScrollView contentContainerStyle={styles.screen} keyboardShouldPersistTaps="handled">
      <Text style={styles.title}>IT311 Study Helper</Text>
      <Text>Enter a question about an IT topic.</Text>
      <TextInput
        accessibilityLabel="Question"
        multiline
        maxLength={2000}
        onChangeText={setPrompt}
        placeholder="Explain an API in two sentences."
        style={styles.input}
        value={prompt}
      />
      <Button disabled={loading || !prompt.trim()} onPress={generate} title="Generate" />
      {loading && <ActivityIndicator accessibilityLabel="Generating an answer" />}
      {error !== '' && <Text accessibilityRole="alert" style={styles.error}>{error}</Text>}
      {answer !== '' && <Text selectable style={styles.answer}>{answer}</Text>}
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  screen: { padding: 24, gap: 16 },
  title: { fontSize: 26, fontWeight: '700' },
  input: {
    borderColor: '#94A3B8',
    borderRadius: 8,
    borderWidth: 1,
    minHeight: 100,
    padding: 12,
    textAlignVertical: 'top',
  },
  error: { color: '#B42318' },
  answer: { backgroundColor: '#F1F5F9', borderRadius: 8, padding: 16, fontSize: 16, lineHeight: 24 },
});

Troubleshooting

Cannot reach the backend

Check that Laravel is running and that your emulator or phone can reach the URL in the React Native .env. Restart Expo after changing the URL.

404 or route not found

Check that bootstrap/app.php loads routes/api.php. The app sends a POST to /api/generate, so opening that address in a browser tab sends a different request.

AI service is not configured

Check the key in the Laravel .env and the Gemini entry in config/services.php. If Laravel is using cached configuration, refresh it.

429 or too many requests

Laravel allows five requests per minute from the same IP address. Wait a minute and try again. Gemini also applies its own quota.
